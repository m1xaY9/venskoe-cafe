# Этапы работ

Каждый пункт — отдельная ветка и отдельный пул-реквест в `main`.

## Цели

- Удобный сайт и на телефоне, и на компьютере (mobile-first).
- Доставка как у Яндекс Еды или Самоката: заказ проходит понятные этапы, гость видит каждый из них на странице заказа.
- Отмена заказа с возвратом денег, пока кухня не начала готовить.
- Свой Telegram-бот: уведомления о заказах в рабочий чат, смена статусов кнопками и статистика.
- В самом конце — Telegram Mini App с тем же меню и доставкой.

## Этап 0. Основа
- [x] `main`: README, правила работы, архитектура, roadmap
- [x] `feature/backend-skeleton`: Go API с /healthz, конфигом из env, логами, корректной остановкой, тестами и CI

## Этап 1. Меню
- [x] `feature/db`: PostgreSQL в Docker, миграции (goose), запросы руками через pgx
- [x] `feature/menu-api`: категории, блюда, стоп-лист; `GET /api/menu`
- [ ] `feature/frontend-skeleton`: Next.js + Tailwind, адаптивная вёрстка, страница меню с данными из API

## Этап 2. Корзина и оформление
- [ ] `feature/cart`: корзина (Zustand + localStorage), анимации, нижняя панель на телефоне
- [x] `feature/delivery-zones`: зоны доставки, подсказки адреса (DaData), минимальная сумма, часы работы
- [x] `feature/orders-api`: создание заказа, пересчёт суммы на сервере, статусы и история `order_events`

## Этап 3. Оплата и возвраты
- [x] `feature/sber-payments`: клиент API Сбера, `register.do` с корзиной для чека 54-ФЗ, callback с перепроверкой статуса, фоновая сверка, автоотмена неоплаченных
- [ ] `feature/refunds`: отмена заказа гостем или кафе с возвратом через Сбер (`reverse.do` в тот же день, `refund.do` позже), правила, когда возврат возможен

## Этап 4. Отслеживание заказа гостем
- [ ] `feature/order-tracking`: страница заказа с этапами (принят → готовится → в пути → доставлен), обновление в реальном времени (SSE), кнопка отмены
- [ ] `feature/notifications-guest`: SMS или Telegram гостю при смене этапа (по желанию)

## Этап 5. Telegram-бот кафе
- [ ] `feature/telegram-bot`: новые заказы в рабочий чат, кнопки смены статуса, доступ только сотрудникам
- [ ] `feature/bot-stats`: команды `/today`, `/week`, `/month`: выручка, число заказов, средний чек, топ блюд, отмены и возвраты

## Этап 6. Админка
- [ ] `feature/admin-auth`: вход для сотрудников
- [ ] `feature/admin-orders`: список заявок, карточка заказа, смена статуса, возврат
- [ ] `feature/admin-menu`: редактирование меню, фото, стоп-лист

## Этап 7. Запуск

- [ ] бэкапы БД, мониторинг, алерты в Telegram
